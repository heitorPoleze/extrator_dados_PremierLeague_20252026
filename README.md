# extrator_dados_PremierLeague_20252026
Mineração de dados do campeonato de futebol inglês Premier League temporada 2025/2026. Pipeline completa de mineração de dados: coleta, limpeza, estruturação, análise estatística e mineração.

Para o projeto funcionar corretamente: 
  1. pip install -r requirements.txt
  2. Rode o Python de preparacao_dados.
  3. Rode o Python de mineracao_xG.
  4. Rode o Python de clusterizacao.py
  
Demora um tempo para extrair tudo, mas acompanhe os avisos pelo terminal. 

O sistema está configurado para não repetir downloads de jogos que já existem na sua pasta local.
